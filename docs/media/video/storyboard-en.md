## Full Voice-over

Managing several Bambu Lab printers should not mean watching several windows. BambuMonitor brings progress, temperatures, filament, and alerts into one desktop workspace. Switch between full, compact, and mini views, resize freely, and keep the monitor on top. Watch multiple cameras together, then open any live view for a closer look. Cloud status stays in sync, while LAN cameras remain direct and responsive. BambuMonitor is now open source on GitHub under AGPL version three.
