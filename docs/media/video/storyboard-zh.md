## 配音全文

多台拓竹打印机，如何一眼掌握？BambuMonitor，把进度、温度、耗材和异常状态集中到一个桌面。完整、紧凑、迷你三种视图，自由缩放，也能常驻置顶。摄像头墙同时查看多台设备，点击即可放大实时画面。云端同步状态，局域网连接摄像头，窗口位置和大小都会记住。BambuMonitor，现已在 GitHub 以 AGPLv3 开源。
