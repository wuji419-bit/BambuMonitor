# BambuMonitor 动态宣传片重制方案

## 目标

将现有截图轮播式宣传片重制为更接近正式软件发布片的动态产品视频。中文版与英文版各一条，使用 `1920x1080`、30fps，并显著提升设备素材清晰度、转场质量、字幕设计和整体节奏。时长由内容和配音自然决定，不设置 30 秒硬限制，预计约 50-65 秒。

## 制作架构

- **Image 2**：重绘低清摄像头素材，恢复打印机结构与舱内细节，改善光线和噪点；将原有紫色打印板统一改成深墨绿色。
- **HyperFrames**：制作品牌开场、指标数字、技术线框、关键词强调、扫描光和场景转场，输出可复用的动态视觉片段。
- **Remotion**：管理最终时间线、界面镜头、重绘设备素材、字幕、配音、背景音乐和中英文版本输出。
- **FFmpeg**：仅用于最终编码参数检查、音量检查和抽帧验收，不再承担主要视觉设计。

## 视觉识别

### 颜色

- 主背景：`#080C12`
- 面板：`#111923`
- 薄荷绿强调：`#66E3B4`
- 冰蓝辅助：`#72B8F4`
- 金色提醒：`#E5B95F`
- 深墨绿打印板：`#163A32`
- 主文字：`#F2F6FA`
- 次文字：`#9CAFC1`

颜色必须保持克制，深墨绿只用于打印板和少量场景呼应，不能让整条视频变成单一绿色主题。

### 字体

- 中文：思源黑体或系统可用的等价无衬线字体。
- 英文：Inter 或系统可用的等价无衬线字体。
- 数字采用等宽数字，便于进度与温度动画稳定对齐。

### 禁止项

- 不使用低清图片直接放大到全屏。
- 不使用简单截图淡入淡出作为主要剪辑方式。
- 不保留紫色打印板。
- 不使用过量霓虹、镜头光斑、渐变球或廉价科技 HUD。
- 不生成无法对应真实功能的按钮、状态或远程控制能力。

## 素材重绘

重绘素材以现有真实打印机摄像头画面为构图参考：

- 保留打印机舱体、喷头、导轨和打印板的基本结构与镜头角度。
- 清除压缩噪点、雾感、过曝和模糊，恢复可辨识的机械细节。
- 将紫色打印板替换为哑光深墨绿色，保持真实材质、透视和反射。
- 不生成账号、IP、品牌水印、随机文字或额外设备。
- 输出至少 `1536x1024` 的高质量横向素材，再由 Remotion 安全裁切到 16:9。

## 内容结构与预计时长

1. **约 0-6 秒：品牌开场**  
   BambuMonitor 标识、核心句和多设备数字以 HyperFrames 动效进入。
2. **约 6-16 秒：多设备状态**  
   展示完整工作区，重点卡片与进度条按真实数据顺序出现。
3. **约 16-26 秒：窗口形态**  
   完整、紧凑、迷你视图通过空间推拉和形态变换衔接，不出现大面积空黑边。
4. **约 26-40 秒：摄像头主镜头**  
   使用 Image 2 重绘的高分辨率设备画面，结合摄像头墙与放大预览界面；打印板为深墨绿色。
5. **约 40-52 秒：设置与可靠性**  
   设置面板、窗口记忆、云端状态与局域网摄像头关键词快速呈现。
6. **约 52-60 秒：开源结尾**  
   GitHub、AGPLv3、Windows / macOS 与项目地址清晰收尾。

上述时间为节奏参考，不是硬切点。最终时长由中英文配音中较长的一版、界面可读时间和镜头呼吸共同决定，两版保持相同场景结构但允许少量语言节奏差异。

## 中英文界面

- 中文视频使用中文导航、状态、设置和摄像头标签。
- 英文视频的应用界面必须完整本地化，不允许只替换配音和字幕。
- Remotion 使用同一套矢量界面组件和中英文字典分别渲染，保证布局、数据和动效一致。
- 英文版至少包含 `Devices`、`Cameras`、`Total`、`Online`、`Printing`、`Attention`、`Settings`、`Camera Wall`、`Local Camera`、`Completed`、`Paused` 等可见界面文案。
- 打印机型号、温度、百分比、层数和 GitHub 项目名保持原始格式，不进行错误翻译。
- 不使用图像模型生成界面文字，避免英文拼写错误；Image 2 只处理无文字的打印机与打印板画面。

## 动效规则

- 每个场景都必须有独立入场动画和场景过渡。
- 使用弹簧、遮罩揭示、景深推拉、卡片错层和适量扫描光。
- 转场期间保持上一场景完整可见，由转场本身完成退出。
- 字幕每次不超过两行，中文约 14-18 字一行，英文按语义分行。
- 界面素材使用局部放大、裁切和景深背景，不出现上一版的狭窄界面居中加大块黑边。

## 声音

- 延用中英文沉稳男声，但重新根据新版镜头节奏校准停顿。
- 背景音乐使用原创合成轻科技节奏，降低持续低频嗡鸣，增加轻微脉冲与转场提示音。
- 配音峰值保持在安全范围，音乐在旁白期间自动压低。

## 验收标准

- 中文、英文视频均为 `1920x1080`、30fps，时长以完整表达和自然节奏为准，预计 50-65 秒。
- 英文版所有可见应用界面文案为英文，不残留中文按钮、标签或设置项。
- 重绘设备素材无紫色打印板，机械结构合理，没有随机文字或水印。
- 所有界面与字幕在手机、桌面和电视观看时均清晰。
- 不出现黑边占据主要画面、字幕贴边、控件遮挡或低清素材全屏拉伸。
- HyperFrames 完成 lint、validate、inspect；Remotion 完成类型检查与最终渲染。
- 抽查开场、窗口切换、摄像头、设置和结尾关键帧。

- 英文宣传片 MP4。

- HyperFrames 工程、Remotion 工程和可重复渲染命令。
- 高分辨率重绘设备素材。
